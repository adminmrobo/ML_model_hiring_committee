SVM — 2つの群れの間に最も広い道を通す

合格の配合と不合格の配合の間に境界を引く方法はたくさんある。今日の応募者はその中から両側の配合から最も遠く離れた境界、言い換えれば2つの群れの間に通せる最も広い道の真ん中を選ぶ。道の幅をマージン、道端に接して道を決めるわずかな配合をサポートベクターと呼ぶ。

まっすぐな道で分けられなければ、カーネルトリックで空間を曲げてまっすぐな道を通す。同じ考えを回帰に移すと、予測線の周りに幅εのチューブを巻き、チューブの外に出た配合だけを罰するSVRになる。だからこの応募者は、分類（SVC）と回帰（SVR）を両方こなす兼用チームである。

1. 最大マージン Maximum Margin

2つのクラスを分ける線はたくさんある。両側から最も遠く離れた、最も広い道の真ん中を選ぶ。

→ 01 自己紹介

2. サポートベクター Support Vectors

道の縁に接した数個の点だけが道を決める。残りの点は消しても道はそのままだ。

w·x + b = 0（中央の線）
w·x + b = ±1（道の縁）
→ 01 自己紹介

3. ソフトマージン Soft Margin · C

本物のデータは重なる。道にはみ出した分（ξ）だけペナルティを与え、その重みをCで決める。

min ½‖w‖² + C · Σ ξi
Cを小さく
広い道
はみ出しに寛容
Cを大きく
狭い道
はみ出しに厳しい
→ 04 試用期間

4. ヒンジ損失 Hinge Loss

道の外の正しい側にあればペナルティは0。縁を越えてきた分だけ直線的に罰する。

L = max(0, 1 − y·f(x)),  y = ±1
→ 04 試用期間

5. カーネルトリック Kernel Trick

直線で分けられなければ、特徴量を増やして空間を曲げる。曲げた空間では、まっすぐな境界1本で分けられる。

計算は曲げた空間ではしない。2つの点の似ている度合いだけをカーネルK(x, x′)で測る。
→ 01 自己紹介

6. RBFカーネルとγ RBF Kernel · Gamma

近いほど1、遠いほど0の釣鐘形の似ている度合い。γが大きいと、すぐ隣だけを似ているとみなす。

K(x, x′) = exp(−γ ‖x − x′‖²)
→ 04 試用期間

7. 標準化は必須 Feature Scaling

距離で似ている度合いを測るので、単位の大きい特徴量が距離を独占する。まず標準化する。

標準化しないと、強度を左右する水と減水剤が距離からほとんど消える（訓練772件の分散の取り分）。
→ 02 実技課題

8. SVRのεチューブ Support Vector Regression

回帰では、予測線の周りに幅±εのチューブを巻く。チューブの中の誤差は罰しない。

|y − f(x)| ≤ ε → ペナルティ0
チューブの外に出た分（ξ）→ C × ξ
→ 04 試用期間

9. 学習 Training · SMO

配合ごとに重みαを置く。最もずれた2つのαを選び、その2つだけを直すことを繰り返す。

f(x) = Σ αi yi K(xi, x) + b
→ 04 試用期間
青：モデル / 接続黒：データ赤い輪：サポートベクター

この1枚を読む順番

1・2番欄が「何を探すか（最も広い道と、道を決める点）」、3・4番が「重なるときにどう折り合うか」、5・6番が「まっすぐな道が引けないとき（カーネル）」、7番が「準備するもの（標準化）」、8番が「回帰に移すと」、9番が「どう学ぶか」である。この面接は01章（1・2・5番）→ 02章（7番）→ 04章（3・4・6・8・9番）→ 05章（分類・回帰の成績）の順に進む。

SV
応募者・SVMロジスティック回帰は、すべての配合の確率を少しずつ合わせようとして境界を動かします。私は境界の近くの配合だけを見ます。それらの配合から最も遠く離れるように、道の真ん中に境界を引きます。遠く離れた配合は消しても、私の答えは変わりません。
実際に触ってみる · 特徴量2個（水結合材比 · log 材齢）でまっすぐな道を通す（訓練配合772件、直線SVM）
計算中…

なぜ最も広い道なのか

境界が一方の群れにぴったり寄っていると、その群れの新しい配合が少し揺れただけで反対側に越えてしまう。両側から等しく遠く離れた境界は、そうした揺れに最もよく耐える。道の幅は、境界の式w·x + bの傾きの大きさ‖w‖で決まる（幅 = 2/‖w‖）。だから「道を広く」は‖w‖を小さくと同じであり、これは5-3・5-4で見た正則化と同じ働きをする。

道の幅 = 2 / ‖w‖  →  ½‖w‖²を最小に

サポートベクターだけを残しても同じ道

上の図の「サポートベクターだけを残して解き直す」を押してみよう。赤い輪の外の配合をすべて消して学習し直しても、境界はそのままである。SVMの答えはサポートベクターだけに頼っているということだ。だから覚えるのはサポートベクターだけで済むが、逆にサポートベクターの1つがでたらめな配合なら、道はそちらへ引っ張られる。ショウジョウバエの質問はまさにこれである。

f(x) = Σサポートベクター αiyi K(xi, x) + b
カーネルの魔法 · 練習用のおもちゃの例（コンクリートのデータではない）：点1つでは分けられない2つの群れ

カーネルトリック — 曲げずに、曲げたかのように計算する

おもちゃの例では、特徴量xにx²を加えて2次元に持ち上げた。特徴量が8個あるコンクリートでこのように掛け合わせた特徴量をすべて作ると、列が数十、数百に増える。SVMは学習と予測で2つの配合の内積（似ている度合い）しか使わないので、曲げた空間の座標を作らずに似ている度合いを直接計算する関数K(x, x′)に差し替えられる。これがカーネルトリックである。最もよく使われるRBFカーネル exp(−γ‖x − x′‖²) は、無限に多くの特徴量で曲げた空間での内積と同じである。γは、1つの配合の影響がどこまで届くかを決める（04章）。

Practical test · Data

実技課題 — 同じ配合表で2科目

1行が1つの配合（サンプル）、配合量と材齢が特徴量(X)、圧縮強度とそこから作ったラベルが目的変数(y)である

科目A · 分類（SVC）

35 MPa合格かどうか（+ 強度3等級）

圧縮強度が35 MPa以上なら合格(1)、そうでなければ不合格(0)。マニュアルさんは作業標準書の1行で試験用紙の76.7%を当てた。常に多数派だけを答えるベースラインは49.6%。3等級（低・普通・高強度）は、SVCが二値分類3つを束ねて解く（一対一の投票）。

科目B · 回帰（SVR）

圧縮強度(MPa)

強度の数値そのものを当てる。マニュアルさんの経験式（エイブラムスの式 + 材齢補正）が試験用紙でR² 0.735（平均絶対誤差6.72 MPa）を出した。常に訓練の平均だけを答えると、平均絶対誤差は13.52 MPaである。

表 · 実技課題の全体 (1,030行)

青い見出しが特徴量(X)、赤い列が目的変数(y)である。科目Aは強度を35 MPaと比べて作ったラベルを、科目Bは強度(MPa)そのものを目的変数に使う。「封印」の印が付いた258行は、05章で一度だけ開ける。

核心の場面 · 標準化しないと、RBFが見る「距離」は誰が決めるのか（訓練772件の分散の取り分）

2つの配合の間の距離の2乗は、特徴量ごとの差の2乗を足したものである。平均してその合計で各特徴量が占める取り分が棒の長さである。標準化すると、8つの特徴量が等しく12.5%ずつを持つ。

SVMで標準化が必須である理由

RBFカーネルは、2つの配合の距離で似ている度合いを測る。標準化しないと、kg単位で数百ずつ動くセメント・スラグ・骨材が距離のほとんどを占め、強度に最も重要な水（1.2%）と高性能減水剤（0.1%）は距離から消える。直線SVMも‖w‖を小さくしようとするので、単位の小さい特徴量の重みだけが不当に押さえつけられる。だから平均を引き、標準偏差で割る。平均と標準偏差は訓練データだけで求める。

データ差し替えの案内 — 自分の工場のデータに替えるには

  • 表形式(CSVなど)で、1行に1つの配合(またはロット)、品質結果の列が1つあればよい。
  • Colabコード(A章)の1番目のセルのデータ読み込み、FEATURES、PASS_MPAの3か所だけを変える。
  • 合格基準は自分の業務の基準に変える。35 MPaと等級の閾値(25・45 MPa)は、このシリーズが授業用に定めた値である。
  • SVMの学習時間は、おおよそ配合数の2乗以上で増える。数万行を超えたら、LinearSVCやカーネル近似（06章）を先に試す。
  • 文字の特徴量（工場、原材料の等級）はワンホットエンコーディングで数値の列に変え、標準化は数値の列にだけ行う。

    双対問題 — 重みの代わりに配合ごとのα
    
      
    「道を広く、はみ出しはCだけ罰する」をそのまま解くと、重みwを探す問題になる。これを裏返して書くと（双対問題）、配合ごとに1つずつ付いた重みαを探す問題になる。このとき配合どうしは内積（似ている度合い）でしか出会わないので、カーネルを差し込める。αは0とCの間にあり、正解側のαの合計と反対側のαの合計が等しくなければならない（Σ αᵢyᵢ = 0）。
    
      
    最大化：Σ αi − ½ ΣΣ αiαjyiyj K(xi, xj)  (0 ≤ α ≤ C)
    
    
    
    
    
      
    SMO — なぜ2つずつなのか
    
      
    Σ αᵢyᵢ = 0を守るには、αを1つだけ動かすことはできない。2つを一緒に動かせば、1つが上がった分だけもう1つが下がって合計が保たれ、その2つの最もよい値は1行の式ですぐに出る。SMO（Platt, 1998）は「今最もずれている2つの配合」を選んで、この1行の計算を繰り返す。scikit-learnのSVC・SVRの中にあるlibsvmが使う方法で、このページも同じルール（ずれが0.001を下回ったら停止）で解く。

    2つのつまみ Cとγ
    
      
    Cは5-4のロジスティック回帰のCと同じ向きである。大きいほどはみ出しを厳しく罰して道が狭くなり、訓練データにぴったり合わせる（正則化が弱い）。γは1つの配合が届く距離である。大きいとすぐ隣の配合だけを似ているとみなすので、境界が配合1つ1つを包んでくねくねになり、小さいと遠くまで届いて境界がほぼ直線になる。上の図でγ = 50を押してみよう。両方大きければ暗記、両方小さければぼやけである。
    
    
    
    
    
      
    εチューブ — 回帰のサポートベクター
    
      
    SVRは「予測がεの内側で当たればよし」とみなす。チューブの中の配合はαが0なので答えに何の影響もなく、チューブの外やチューブの上の配合だけがサポートベクターになる。εを大きくするとサポートベクターが減って覚えるものが減り、大きくしすぎるとチューブがゆるくなって予測がぼやける。scikit-learnの既定値ε = 0.1は目的変数の単位（ここではMPa）なので、強度に比べるととても狭い。だから05章の8特徴量のSVRでは、訓練配合の大半がサポートベクターになる。

    06
    
    
    Personnel card · Conclusion
    
    
    人事カード — どこに配属し、どう使うか
    
    
    強みと弱み、向いている仕事と向いていない仕事、勤務条件(ハイパーパラメータ)
    
  
    
  
    
    
    
      
    SVAPP-08 → EMP-0008SVM (SVC · SVR)教師あり本部 › 兼用チーム
    
      
    ひとこと評：境界の近くだけを見る道案内。中くらいの大きさの表データで、曲がった境界もうまく引く。その代わり標準化とC・γ選びを必ず面倒見てやる必要があり、データが大きくなると遅くなる。
    
    
    
    
    
      
    
        
    強み
    
        
      
          
    • 曲がった境界を引く。カーネル1つで、直線（ロジスティック回帰）にはできない境界を作る。分類の正解率は5-4より高い（05章）。
      • 
          
    • 同じ枠組みで回帰まで。εチューブを巻けばSVRになる。兼用チームの資格である。
      • 
          
    • 答えが1つに決まる。問題が凸なので、何回実行しても同じ道にたどり着く（乱数によって変わらない）。
      • 
          
    • 特徴量が多くても持ちこたえる。道を広くすること自体が正則化なので、特徴量の数が配合の数より多いデータ（文章、遺伝子）でも使う。
      • 
        
    
      
    
      
    
        
    弱み
    
        
      
          
    • 勤務条件に敏感である。既定値C = 1では回帰が採用ラインを下回る（面接結果の「条件を変えてみる」）。C・γを交差検証で選ばなければならない。
      • 
          
    • 標準化が必須である。省くと回帰が採用ラインを下回る。
      • 
          
    • データが大きいと遅い。学習が配合数の2乗〜3乗で増える。数十万件なら別の応募者を呼ぶ。
      • 
          
    • 確率と説明に弱い。基本の出力は「道からの距離」である。RBFカーネルの境界は重みのようには読めない。
      • 
        
    
      
    
    
    
  
    
  
    
    勤務条件 · よくいじるハイパーパラメータ（scikit-learn SVC / SVR）
    
    
      
    引数既定値意味と使い方
    
      
        
    C1.0はみ出しのペナルティの重み。大きいほど正則化は弱い（5-4のロジスティック回帰のCと同じ向き、5-3のリッジ回帰のalphaとは逆）。このデータでは、交差検証で分類10、回帰100を選んだ。対数目盛（0.1, 1, 10, 100…）で探す。
    
        
    kernel"rbf""linear"（直線）、"poly"（多項式）、"rbf"（釣鐘形）、"sigmoid"。まずrbfとlinearを比べる。多項式3次は、この試験用紙で91.5%だった（A章）。
    
        
    gamma"scale"RBF・多項式カーネルが届く距離の逆数。"scale" = 1/(特徴量の数 × X.var())。大きいとくねくね（暗記）、小さいとのっぺり。Cと一緒にグリッド探索する。
    
        
    epsilon (SVR)0.1εチューブの半幅。目的変数の単位である（ここではMPa）。大きくするとサポートベクターが減って軽くなり、大きくしすぎるとぼやける。
    
        
    class_weightNone"balanced"なら、数の少ないクラスのはみ出しペナルティを大きくする。不良が数%しかないときに使う。
    
        
    probabilityFalseTrueなら確率（Platt補正）を出す。内部の交差検証のため、学習が数倍遅くなる。確率が必要なら、ロジスティック回帰もあわせて検討する。
    
          
    
    
  
    
  
    
    
    
      予算 · 覚えるものと1回の予測の計算（ブラウザで計算）
      
    05章を開くと計算する。
    
      
    カーネルSVMは、予測のたびに新しい配合とサポートベクター1つ1つの似ている度合いを測る。ロジスティック回帰は掛け算8回で終わる。
    
    
    
    
    
      向いている仕事 · 向いていない仕事
      
    
        
    向いている仕事数百〜数万件の表データで曲がった境界が必要な判定、特徴量が多くサンプルが少ないデータ（分光データ、文章の単語頻度）、結果が再現されなければならない判定（同じデータならいつも同じ答え）
    
        
    向いていない仕事数十万件を超えるデータ（学習時間）、確率や理由を説明しなければならない判定（→ 5-4 ロジスティック回帰）、単位の混ざった生のデータを手を加えずにそのまま入れる仕事（→ 5-6・5-7 木の系統）
    
        
    補足大きなデータでは、LinearSVC（直線、速い）か、RBFをまねる特徴量を作って直線のモデルに入れるカーネル近似（Nystroem、RBFSampler）を使う。
    
      
    
    
    
  
    
  
    
    
    人事担当の助手配属条件を書いておきますね。第一に、標準化したデータだけを渡す。第二に、Cとγは訓練データの中で交差検証により決める。第三に、配合が数万件を超えたら、ほかの応募者とコストを比べる。次の面接は5-9 GBMです。

      • 重なるデータはソフトマージンCで折り合いをつけ、まっすぐな道が引けなければカーネルで空間を曲げる。実際には曲げずに、似ている度合いだけを測る

      設定と注意事項
      このページのデータ、図、コンセプトについての案内
      
  
      • データと計算。実技課題はUCIのコンクリート圧縮強度データ1,030件で、試験用紙はtest_size=0.25、stratify=強度3等級、random_state=42で分けた258件である。回帰の採用ラインは、マニュアルさんの現場の経験式（エイブラムスの式を水結合材比に広げ、ACI 209Rの材齢補正を掛けた式、学習なし）が試験用紙で出したR²である。35 MPaの合格基準と25・45 MPaの等級の閾値は授業用に決めた値である。01章・04章・05章・06章と面接結果のSVMは、すべてこのページがブラウザで直接学習する。scikit-learnのSVC・SVRの中にあるlibsvmと同じ双対問題を同じ方法（SMO、2次情報で2つのαを選ぶ、許容誤差0.001）で解くが、縮小（shrinking）とカーネルキャッシュの代わりに、カーネル行列全体をあらかじめ作る。そのため、サポートベクターの数が1〜2個、正解率が0.1ポイント前後、Colabの結果（A章）と異なることがある。事前に計算して入れた値は05章の交差検証の分割番号（訓練772件が5つのうちどこに入るか、A章のコードと同じStratifiedKFold・KFold、random_state=42）だけで、スコアはブラウザがその分割どおりに学習して計算する。01章のカーネルの魔法は練習用のおもちゃの点である。03章の「AIが出したコード」はよくある間違いを集めてわざと作った例であり、特定のAIサービスの実際の答えではない。
      • 応募書類・1枚目。各回00章の9マスの応募書類は、このシリーズのために新しく描いた。ロジスティック回帰の回は、広く使われている9マスの要約インフォグラフィックの構成(二値分類 → 線形スコア → シグモイド関数 → 確率 → 境界 → 閾値 → 損失 → 学習 → 多クラス分類)にならい、元の図とロゴは転載していない。
