多項式回帰と正則化 — 曲線を引き、手綱をつける

コンクリート強度は材齢とともに、最初は速く、後はゆっくり上がる。直線1本ではこの曲がりについていけない。今日の応募者は、特徴量をべき乗し、互いに掛け合わせて増やしてから、その上で線形回帰を行う。特徴量は増えたが、モデルは相変わらず「重みを掛けて足す」である。だから名前が多項式回帰なのである。

特徴量が8個から164個に膨れ上がると、訓練配合を暗記しやすくなる。そこで応募者は正則化という手綱も一緒につける。重みが大きくなるほど罰則を与え、曲線が好き勝手に曲がれないようにする。罰則の与え方によって3兄弟がいる。均等に縮めるリッジ回帰、0に消すラッソ回帰、2つを混ぜるElastic Netである。

1. 曲線の関係 Non-linear Relationship

強度は材齢とともに、最初は速く、後はゆっくり上がる。直線はこの曲がりについていけない。

→ 02 実技課題

2. 多項式特徴量 Polynomial Features

特徴量xをx²、x³に増やす。モデルは相変わらず、重みを掛けて足す線形回帰である。

ŷ = w1x + w2x2 + w3x3 + b
→ 01 自己紹介

3. 特徴量の爆発 Feature Explosion

特徴量が複数あると、べき乗に加えて互いに掛け合わせた項(x₁x₂)まで付く。次数を上げると急速に膨れ上がる。

特徴量の数 = C(8 + d, d) − 1
d = 次数、8 = 元の特徴量の数、−1 = 定数の列
→ 02 実技課題

4. 最小二乗法 Least Squares

残差（正解 − 予測）の二乗和を最も小さくする重みを探す。5-2 線形回帰と同じ方法である。

最小化  Σ (yi − ŷi)2
→ 04 試用期間

5. 過学習 Overfitting

次数を上げると訓練スコアは上がり続けるが、初めて見るデータのスコアはある時点で崩れる。

→ 05 人事考課

6. リッジ回帰 (L2) Ridge Regression

重みの二乗和に罰則を与える。すべての重みを0の方へ均等に縮める（0にはならない）。

Σ(y − ŷ)2 + α Σ wj2
→ 04 試用期間

7. ラッソ回帰 (L1) Lasso Regression

重みの絶対値の和に罰則を与える。役に立たない重みをいっそ0に消す（特徴量選択の効果）。

12nΣ(y − ŷ)2 + α Σ |wj|
→ 04 試用期間

8. Elastic Net Elastic Net

L1とL2を比率ρ(l1_ratio)で混ぜる。消すこともあれば、互いに似た特徴量を一緒に残すこともある。

… + α [ ρ Σ|w| + 1 − ρ2 Σw2 ]
→ 05 人事考課

9. αを選ぶ Choosing α (Cross-Validation)

αが小さいと過学習、大きいと未学習。試験用紙ではなく、訓練データの中の交差検証で選ぶ。

αが大きいほど正則化が強い。ロジスティック回帰・SVMのCは逆向きである(C ≈ 1/α)。
→ 05 人事考課

01
Self-introduction · Concept

自己紹介 — 特徴量を増やして曲線を引き、手綱で抑える

特徴量 x → x, x², x³, … → 線形回帰 → 正則化αで重みを押さえる

λ
応募者・多項式回帰と正則化私は直線しか引かない線形回帰に、もっと材料を与えます。xの横にx²とx³を付けてやれば、同じように「掛けて足す」だけで曲線になります。ただ、材料が多すぎると点の1つ1つを追いかけようと身をよじります。そのときαが手綱を引きます。
触ってみる・水結合材比1つで28日強度を（訓練配合12件にわざと減らしたおもちゃの問題）

多項式回帰も「線形」回帰である

曲線を描くのに、なぜ線形なのか？モデルがやっていることは、相変わらず特徴量ごとに重みを掛けて足すことだけである。変わったのは特徴量の側である。xの代わりに[x, x², x³]を入れただけである。重みに対して線形なので、5-2 線形回帰の最小二乗法をそのまま使う。特徴量が複数あれば、x₁·x₂のように互いに掛け合わせた交互作用項も付く。「セメントが多いときほど材齢の効果が大きい」といった関係を、この項が受け持つ。

ŷ = w₁x + w₂x² + w₃x³ + b  ← wに対して線形

正則化は罰則である

最小二乗法は訓練誤差しか見ない。特徴量が多いと、非常に大きな重みどうしが打ち消し合い、点の1つ1つを通る曲線を作ってしまう。正則化は損失に「重みが大きければ罰則」を加える。αがその罰則の強さである。α = 0なら正則化はなく、αが大きいと重みが0の方へ押さえられて曲線がまっすぐになる。大きすぎると、直線にも劣る平らな線になる（未学習）。

損失 = 誤差²の和 + α ×（重みの大きさ）

上の図で見るべきこと

次数を1 → 3に上げると、曲線が点の曲がりについていく。10まで上げてαを0にすると、曲線は黒い点（訓練）の間で上下にうねり、灰色の点（テスト）では大きく外れる。訓練R²は上がるのに、テストR²は負に落ちる。これが過学習である。では次数は10のままでαだけを上げてみよう。曲線が落ち着き、テストR²が戻ってくる。この面接全体は、この1枚の図をコンクリートデータ全体（特徴量8個、164個）に広げたものである。

02
Practical test · Data

実技課題 — コンクリート配合1,030件、強度を数値で当てる

1行が1つの配合(サンプル)、配合量と材齢が特徴量(X)、圧縮強度(MPa)が目的変数(y)である

本試験・回帰

圧縮強度(MPa)を当てる

合格／不合格のラベルではなく、強度の数値そのものを当てる。成績はR²（1なら完璧、0なら「常に平均」と同じ、負ならそれより劣る）とMAE（平均で何MPa外れるか）で測る。常に訓練平均を答えるベースラインは、テストMAE 13.52 MPa、R² 0である。

採用ライン・マニュアルさんの現場の経験式

R² 0.735 · MAE 6.72MPa

マニュアルさんは学習しない。教科書のエイブラムスの式で28日強度を出し、材齢補正式で日数を合わせる。人間の知識だけでこれだけ当てる。水結合材比の代わりに水セメント比を入れると、R²は0.058まで崩れる。スラグ・フライアッシュも固まるという知識が入ってこそ、式が合う。

f₂₈ = 96.5 / 7(水結合材比) MPa  ·  f(t) = f₂₈ · t / (4 + 0.85t)
図 · 軸を選んで見る (色 = 強度等級、中が空の点 = 封印された試験用紙)
基本の図は材齢（横、対数目盛ではない）と強度（縦）である。最初の28日まで急に上がり、その後ゆるやかになる曲がりが見える。直線1本ではこの形についていけない（応募書類のマス1）。
特徴量は何個に膨れ上がるか・次数を選んでみる（応募書類のマス3）
表 · 実技課題の全体 (1,030行)

青い見出しが特徴量(X)、赤い列が目的変数(y)である。5-4の分類チームは、同じ強度を35 MPaの閾値に当ててラベルに変えて使った。同じデータ、違う質問である。「封印」の印が付いた258行は05章で一度だけ開ける。一番右の列は、マニュアルさんの経験式が出した予測である。

なぜ2回標準化するのか

まず元の特徴量8個を標準化する（平均0、標準偏差1）。そのままべき乗すると、粗骨材1,000 kgの三乗は10億になり、高性能減水剤は数十のままで、数値の大きさの差が手に負えなくなる。多項式特徴量を作った後、もう一度標準化する。正則化は「重みの大きさ」に罰則を与えるので、列ごとに単位が違うと罰則が不公平になる。2回とも、平均と標準偏差は訓練データだけで求める。

元の特徴量 → 標準化 → 多項式特徴量（164個）→ 標準化 → リッジ回帰・ラッソ回帰・Elastic Net

データ差し替えの案内 — 自分の工場のデータに替えるには

  • 表形式(CSVなど)で、1行に1つの配合(またはロット)、当てたい数値の列が1つあればよい。
  • Colabコード（A章）のセル1のデータ読み込みとFEATURESの2か所だけを変える。マニュアルさんの経験式（セル3）は、自分の業務の経験式や既存の計算表に置き換える。
  • 特徴量が20個を超えるだけで、3次の多項式特徴量は1,770個になる。配合の数より特徴量が多くなると、正則化なしでは解けない。2次から始める。
  • 文字の特徴量（工場、原材料の等級）はワンホットエンコーディングで数値の列に変える。ワンホットの列はべき乗しても同じ値なので、交互作用項だけが意味を持つ(interaction_only)。
  • 強度の範囲外の配合（非常に低い水結合材比など）では、多項式の曲線が大きく外れやすい。データの範囲を記録しておき、その外では使わない。

    計算の準備中…
    
    
    再生はα = 100から始まり、0.001まで下がる。各αで、前のαの答えを出発点にして解き直す（ウォームスタート）。「座標降下法を1周」は、ラッソ回帰・Elastic Netで重みをすべて0に置き、今のαで1周（164個を1つずつ）ずつ更新する。リッジ回帰は一度に解けるので、1周で終わりである。下の線グラフのテストR²は説明用に見せているだけで、αを選ぶのに使えば反則である（05章の交差検証）。
    
  
    
  
    
    
    
      
    リッジ回帰は一度に解く — 閉形式解
    
      
    誤差の二乗和にα·Σw²を足した損失はなめらかなお椀の形なので、底を1つの式で直接求められる。5-2 線形回帰の正規方程式の対角線にαを足したものである。このαのおかげで、特徴量どうしがほぼ同じ情報を持って（条件数が大きくて）解が揺れるときでも、答えが安定する。これが1970年にリッジ回帰が初めて登場した理由である。
    
      
    w = (XᵀX + αI)⁻¹ Xᵀy
    
    
    
    
    
      
    ラッソ回帰は1つずつ更新する — 座標降下法
    
      
    絶対値|w|は0で尖っているので、1つの式では解けない。そこで重みを1つずつ順番に更新する。j番目の重みだけを動かすと考えると、答えは「ほかの重みで説明した残りの取り分(ρⱼ)」をαだけ削った値である。残りの取り分がαより小さければ正確に0になる。この削り方をソフト閾値処理と呼ぶ。164個を1周し、変わらなくなるまで繰り返す。
    
      
    wⱼ ← S(ρⱼ, α) = sign(ρⱼ) · max(|ρⱼ| − α, 0)
    
    
    
  
    
  
    
    
    予算担当 Money-Roboラッソ回帰は気に入った。α = 0.1なら164個のうち98個を0に消すから、覚える数字が66個（+ 切片）に減るじゃないか。リッジ回帰は1つも消さずに、全部を少しずつ削るだけだ。

    リッジ回帰のα = 1は、上の交差検証が選んだ値である。ラッソ回帰・Elastic Netのα = 0.1は説明のために選んだ値である（実務ではLassoCV・ElasticNetCVで選ぶ）。ラッソ回帰とElastic Netは損失を2nで割って使うので（応募書類のマス7）、同じαでもリッジ回帰と強さを直接比べることはできない。

    Personnel card · Conclusion
    
    
    人事カード — どこに配属し、どう使うか
    
    
    強みと弱み、向いている仕事と向いていない仕事、勤務条件(ハイパーパラメータ)
    
  
    
  
    
    
    
      
    λAPP-03 → EMP-0003多項式回帰と正則化教師あり本部 › 回帰チーム
    
      
    ひとこと評：材料を増やして曲線を引き、手綱で制御する線形回帰。次数とαの2つのつまみをうまく握れば、経験式を超える。つまみを放すと暴走する。
    
    
    
    
    
      
    
        
    強み
    
        
      
          
    • 曲線と交互作用をとらえる。人がlog(材齢)や水結合材比を作ってやらなくても、3次の項が曲がりをまねる（R² 0.567 → 0.849）。
      • 
          
    • 相変わらず線形回帰である。学習が速く（リッジ回帰は式1つ）、同じ入力なら常に同じ答えである。
      • 
          
    • 正則化で安全装置をつける。リッジ回帰は不安定な解を安定させ、ラッソ回帰は役に立たない項を消してモデルを軽くする。
      • 
          
    • ほかの応募者の材料になる。多項式特徴量 + ロジスティック回帰、多項式カーネルのSVM(5-8)が同じ考え方を使う。
      • 
        
    
      
    
      
    
        
    弱み
    
        
      
          
    • 特徴量が爆発する。特徴量8個の4次なら494個、20個の3次なら1,770個である。配合の数より多くなると、正則化なしでは解けない。
      • 
          
    • データの範囲の外で暴れる。べき乗は範囲を少し外れるだけで値が大きく跳ね上がる。4次の暴走がまさにこれである。
      • 
          
    • 説明が難しくなる。「材齢²・セメント」のような項の重みは人には読みにくい。ラッソ回帰が消しても、残った項が原因だという意味ではない。
      • 
          
    • つまみが2つある。次数とαを一緒に選ぶ必要があり、どちらも交差検証が必要である。
      • 
        
    
      
    
    
    
  
    
  
    
    ラッソ回帰が残した項・3次の多項式特徴量164個のうち0でない重み（標準化した特徴量基準、大きい順に12個）
    
    
    
    
    
    
  
    
  
    
    勤務条件・よく調整するハイパーパラメータ (scikit-learn)
    
    
      
    引数既定値意味と使い方
    
      
        
    PolynomialFeatures(degree)2次数。2から始めて交差検証で上げる。このデータでは3次が最も良く、4次は正則化なしでは暴走した（05章）。
    
        
    include_biasTrue定数の列(1)を作るかどうか。後に続く回帰モデルが切片を別に持つのでFalseにする。Trueだと3次の特徴量は165個と数えられる。
    
        
    interaction_onlyFalseTrueだとx²・x³なしで、互いに掛け合わせた項(x₁x₂)だけを作る。ワンホット特徴量のように、二乗しても同じになる列に使う。
    
        
    alpha (Ridge·Lasso·ElasticNet)1.0正則化の強さ。大きいほど強い。ロジスティック回帰・SVMのCとは向きが逆である(C ≈ 1/α)。RidgeCV・LassoCV・ElasticNetCVが交差検証で選ぶ。
    
        
    l1_ratio (ElasticNet)0.5L1の比率ρ。1ならラッソ回帰、0に近ければリッジ回帰。互いに似た特徴量が多いときは、0.5付近で両方を一緒に残す。
    
        
    max_iter, tol (Lasso·ElasticNet)1000, 1e-4座標降下法の反復回数の上限と停止基準。小さいαでConvergenceWarningが出たら、max_iterを増やす。
    
          
    
    
  
    
  
    
    
    
      αとC — 同じつまみ、逆の目盛り
      
      
    C ≈ 1/αと覚える。赤い側が「重みを強く押さえる」である。5-4 ロジスティック回帰の03章の間違い探しに、この向きのミスが出てくる。
    
    
    
    
    
      向いている仕事 · 向いていない仕事
      
    
        
    向いている仕事特徴量が数個〜数十個の表データで、曲がった関係と交互作用をとらえるとき（配合 → 強度、温度・圧力 → 歩留まり）、経験式をデータで磨くとき、速くて常に同じ答えが必要な予測
    
        
    向いていない仕事特徴量が数百個以上のデータ（多項式特徴量が爆発する）、学習範囲の外を予測する必要がある仕事（外挿）、階段のように折れ曲がる関係（→ 決定木 5-6）、画像・音のような生のデータ
    
        
    補足ラッソ回帰は「正則化」である。役に立たない項を消した結果として特徴量を選ぶが、水結合材比のような意味のある新しい特徴量を作ってくれるわけではない（特徴量エンジニアリングは人の役目）。5-2で特徴量8個に人が作った特徴量2つ（水結合材比、log材齢）を足して出したR² 0.842（覚える数字11個）と、3次の164個で出した0.849はほぼ同じである。

      「5-3 多項式回帰と正則化」の面接を最後まで見届けました。委員会がひとことずつ残します。
      
  
      
  
  
      
    
      委員長の博士今日の応募者は3つのことを見せてくれました。
      • 特徴量をべき乗し、掛け合わせれば、線形回帰が曲線を引く。モデルはそのまま、材料だけが変わる
      • 材料が多すぎると訓練配合を暗記する。4次は訓練R² 0.98、テストR²は大きく負だった
      • 正則化は手綱である。リッジ回帰は均等に縮め、ラッソ回帰は0に消し、Elastic Netは混ぜる。手綱の強さαは、試験用紙ではなく交差検証が決める
      
    
      人事担当の助手3次の多項式回帰が採用ラインR² 0.735を超えました。勤務条件2行を人事カードに書いておきます。次数は3まで、4次を使うならリッジ回帰のαを交差検証で決めること。
      
    
      実務面接官のショウジョウバエ4次がいちばん怖かったぞ。訓練スコアだけを見ていたら、0.98の最優秀応募者として採用してただろう。初めて見る配合の強度をマイナスと言う社員をな。
      
    
      予算担当 Money-Robo数字165個で、MAEがマニュアルさんより2 MPa小さいね。僕はラッソ回帰の方がいいな。半分以上消してもスコアはほぼ同じだから、コスパ最高だ。

      Notes
      設定と注意事項
      このページのデータ、図、コンセプトについての案内
      
  
      • データと計算。実技課題はUCIのコンクリート圧縮強度データ1,030件であり、試験用紙はtest_size=0.25、stratify=強度3等級、random_state=42で分けた258件である。回帰チームの採用ラインは、マニュアルさんの現場の経験式（エイブラムスの式 f28 = 96.5 / 7^(水結合材比) MPa にACI 209Rの材齢補正 t / (4 + 0.85t) を掛けたもので、水セメント比の代わりに水結合材比に広げて使う）が試験用紙で出したR² 0.735である。定数は教科書の値をそのまま使っており、特定の工場の設計基準に代わるものではない。01章・04章・05章・06章と面接結果の数値は、このページがブラウザで直接計算する。多項式特徴量はscikit-learnのPolynomialFeatures(include_bias=False)と同じ順序で作り（3次で164個、定数の列まで数えると165個）、リッジ回帰は閉形式解（コレスキー分解）、ラッソ回帰・Elastic Netはscikit-learnと同じ目的関数を座標降下法で解く。3次まではブラウザの計算が十分に速いので、次数や特徴量を減らしたデモ用のモデルは使っていない。01章の曲線の図だけが、説明のために28日の配合のうち12件、特徴量1つ（水結合材比）に減らしたおもちゃの問題である。4次の多項式回帰（特徴量494個、正則化なし）は解が非常に不安定で（条件数 約10⁶〜10⁷）、テストR²が計算方法によって大きく変わる。ブラウザ（正規方程式）では約−23.6、Colab（scikit-learnのLinearRegression）では−6.18、多項式の後にもう一度標準化すると−11.3になる。数値は違っても、「訓練0.98、テストは大きく負」という結論は同じである。交差検証は、訓練配合を順番に5つに振り分ける方式（ColabのPredefinedSplitと同じ）である。03章の「AIが出したコード」はよくあるミスを集めてわざと作った例であり、特定のAIサービスの実際の回答ではない。
      • 応募書類・1枚目。各回00章の9マスの応募書類は、このシリーズのために新しく描いた。ロジスティック回帰の回は、広く使われている9マスの要約インフォグラフィックの構成(二値分類 → 線形スコア → シグモイド関数 → 確率 → 境界 → 閾値 → 損失 → 学習 → 多クラス分類)にならい、元の図とロゴは転載していない。
      • 図。登場人物の図は「人工知能アルゴリズム・ファミリー組織図」から再利用した。面接室の場面、社員証、図表はこのページがコードで直接描いている。
      • 「採用委員会」コンセプト。モデルを応募者に、学習と評価を面接にたとえた比喩である。実際の採用手続きや特定の会社を表すものではない。不採用は「この仕事に合わない」という意味にすぎず、モデルの優劣ではない。
      • 登場人物。Money-Roboは著者が運営するサービスのマスコットキャラクターである。博士・助手・ショウジョウバエ研究員・マニュアルさん・応募者は実在の人物を表すものではない。セリフ中のお金・予算の表現は、計算コストをたとえた口癖である。
      • データ。教師あり本部の実技課題は、UCI Machine Learning RepositoryのConcrete Compressive Strengthデータ(Yeh, 1998, 1,030件, CC BY 4.0)である。試験用紙の分け方は全回共通で test_size=0.25, stratify=強度3等級, random_state=42(訓練 772 · 試験 258)である。強度等級(25・45 MPa)と合格基準(35 MPa)はこのシリーズが授業用に定めた閾値であり、特定の設計基準に代わるものではない。
