逻辑回归 — 名叫回归，干的是分类

在第0集，手册先生斩钉截铁地回答：“水胶比低于 0.5 且养护 28 天以上就合格。”今天的应聘者回答方式不同：“这个配合比超过 35MPa 的概率是 0.82。”

逻辑回归把特征乘以权重相加，得到线性得分，再把得分送进名为 Sigmoid函数的 S 形曲线，变成 0 到 1 之间的概率。概率超过设定的阈值（通常是 0.5），就判为那个类别。它只靠一条直线工作，但因为用概率作答，还能告诉你“有多大把握”。

1. 二分类 Binary Classification

估计属于类别 1 的概率，再用阈值判为 0 或 1。

→ 02 实操考题

2. 线性得分 Linear Score

把输入特征乘以权重后相加（线性组合）。

z = w1x1 + w2x2 + b
→ 01 自我介绍

3. Sigmoid函数 Sigmoid Function

把线性得分 z 送进 Sigmoid函数，变成 0~1 之间的概率。

σ(z) = 11 + e−z
→ 01 自我介绍

4. 概率预测 Probability Prediction

Sigmoid函数的输出就是属于类别 1 的概率 P(y=1 | x)。

P(y=1 | x) = σ(z) = 11 + e−z
P(y=0 | x) = 1 − P(y=1 | x)
→ 01 自我介绍

5. 决策边界 Decision Boundary

在特征空间中，一条直线（平面）把两个类别分开。就是 z = 0 的地方。

→ 04 试用期

6. 阈值 Threshold

把概率与阈值（通常为 0.5）比较，变成类别标签。

P(y=1 | x) < 0.5 → 判为类别 0
P(y=1 | x) ≥ 0.5 → 判为类别 1
→ 05 绩效考核

7. 损失函数 Loss Function

朝着让二元交叉熵损失最小的方向学习。

L = −[ y log(p) + (1−y) log(1−p) ]
其中 p = P(y=1 | x)
y = 1 时

L = −log(p)
p 越低罚分越大
y = 0 时

L = −log(1−p)
p 越高罚分越大
→ 04 试用期

8. 训练 Training

调整权重 w 和截距 b，使训练数据上的损失减小。

→ 04 试用期

9. 多分类 Multiclass Classification

用 Softmax函数扩展到类别有多个的问题（多项逻辑回归）。

Softmax函数把得分变成 K 个类别的概率（总和为 1），并选出概率最大的类别。

01
Self-introduction · Concept

自我介绍 — 把得分变成概率的员工

线性得分 z → Sigmoid函数 σ(z) → 概率 → 阈值

σ
应聘者 · 逻辑回归我分两步工作。先把每个特征乘以权重相加，得出一个得分。再把这个得分送进 S 形曲线，变成概率。概率超过 0.5，我就回答“35MPa 合格”。
动手试试 · 只用水胶比求合格概率（训练配合比 772 组）

得分 z 是什么

z = w·x + b 和 5-2 线性回归建立的式子完全一样。不同之处在于，这个数不作为答案输出。z 是可以取 −∞ 到 +∞ 任意值的“支持合格的证据大小”。0 表示一半一半，越大越偏向合格，越小越偏向不合格。水胶比越大强度越低，所以权重 w 是负数。

z = w·(水胶比) + b  (w < 0) →  p = σ(z) = 1 / (1 + e−z)

为什么名字叫“回归”

把概率 p 换成几率 p/(1−p) 再取对数，就又回到 z。也就是说，逻辑回归是用直线对对数几率做回归的模型。这个对数几率叫作 logit，它的反函数就是 Sigmoid函数（逻辑函数）。它回归的对象是概率的对数几率，用结果去做的事是分类。

log( p / (1 − p) ) = z = w·x + b

点为什么会重叠

上下两行的点重叠得相当多。即使水胶比相同，养护 7 天和养护 90 天的试件强度也不同。只用一个特征，上下两行重叠是理所当然的，所以答案必须是概率，而不是 0/1。在第04章把龄期作为第二个特征加进去，重叠就会大大减少。

为什么不能用线性回归做分类

点一下上图中的“换成线性回归会怎样？”。把合格设为 1、不合格设为 0 来拟合直线，水胶比非常低的配合比会得到大于 1 的值，非常高的会得到小于 0 的值。这无法读作概率。而且只要进来几个极端配合比，直线就会被拉向它们，等于 0.5 的位置也会莫名移动。Sigmoid函数把两端固定在 0 和 1，所以不会出现这种情况。

02
Practical test · Data

实操考题 — 1,030 组混凝土配合比，8 个特征

一行是一个配合比（样本），各材料用量和龄期是特征 (X)，由抗压强度做成的标签是目标 (y)

考题 A · 二分类（正式考试）

35 MPa 是否合格

抗压强度 35MPa 及以上为合格（1），否则为不合格（0）。训练配合比 772 组中有 48.8% 合格。这就是手册先生用作业标准书的一行字答对试卷 76.7% 的那道题（申请表第1~8格）。

考题 B · 多分类（附加考题）

强度三档

低强度（低于 25MPa）· 普通强度（25~45）· 高强度（45 及以上）。试卷中分别有 74 · 116 · 68 组。用 Softmax函数给出三个等级的概率（申请表第9格）。

图 · 选择坐标轴（颜色 = 强度等级，空心点 = 已密封的试卷）
表 · 完整的实操考题（1,030 行）

蓝色表头是特征 (X)，红色列是目标 (y)。抗压强度 (MPa) 本身是回归组（5-1~5-3）的目标，这场面试使用的是把它与阈值比较后做成的标签。标有“已密封”的 258 行只在第05章打开一次。

为什么要标准化

粗骨料接近 1,000kg，高效减水剂只有几 kg，龄期为 1~365 天。直接放进去，数值大的特征会左右得分 z；而正则化（C）惩罚大权重，罚分就会随单位而变。所以每个特征都要减去均值、除以标准差。均值和标准差只用训练数据来求。把试卷也混进去求，就等于提前偷看了考题。

更换数据说明 — 想换成自己工厂的数据时

  • 只要是表格形式（CSV 等），每行一个配合比（或批次），有一列质量结果即可。
  • 只需修改 Colab 代码（A章）第 1 格中的三处：数据读取、FEATURES、PASS_MPA。
  • 把合格标准换成自己业务的标准。35 MPa 和等级阈值（25 · 45 MPa）是本系列为教学设定的值。
  • 文字型特征（工厂、原材料等级）用独热编码转换成数值列。空白先填补或删除。
  • 先数一数合格·不合格的比例。如果不合格只占百分之几，就不看准确率，改看召回率·精确率（第05章）。

    动画 · 用 2 个特征划分 35MPa 合格的试用期（训练配合比 772 组）
    
    
      
    
    
    
    
    
      
    
      
    
        
    
    
    
    
    
      
      
      
    
    
    
    
    
    点击一个点，就能看到该配合比的概率和损失（申请表第7格）。龄期分布在 1~365 天，所以用对数刻度绘制，模型中也放入了 log(龄期)。在两个按钮之间切换，看看“同一个应聘者、不同特征”的差别。专家特征正是第0集手册先生用过的那两个数。
    
  
    
  
    
    
    
      
    一步之中发生的事
    
      
    对所有训练配合比 ① 算出得分 z，② 变成概率 p，③ 与正确答案 y 比较、量出损失。④ 然后把权重朝损失减小的方向挪一点。逻辑回归的梯度简单得惊人：就是每个配合比的“错了多少（p − y）”乘以特征 x 后取平均。
    
      
    w ← w − η · 平均[ (p − y) · x ] − η·(正则化项)
    b ← b − η · 平均[ (p − y) ]
    
    
    
    
    
      
    为什么用交叉熵
    
      
    正确答案是合格（y=1）时，若说 p=0.99，损失为 −log 0.99 ≈ 0.01；若说 p=0.01，则为 −log 0.01 ≈ 4.6。自信地答错会被重罚。如果用误差平方，与 Sigmoid函数结合后损失曲面会凹凸不平；交叉熵是凸的，梯度下降总能到达同一个谷底。
    
      
    scikit-learn 用比梯度下降更快的方法（lbfgs 等）求解同一个损失。到达的谷底相同。
    
    
    
  
    
  
    
    
    预算官 Money-Robo培训费真便宜。一步就几次乘法，全记下来也就三个数（w₁, w₂, b）。八个特征全用上，九个数就搞定。

    一句话评语：用概率作答的直线。简单、快速、可解释。边界是直线这一局限，只要把特征做好，大部分都能克服。
    
    
    
    
    
      
    
        
    优点
    
        
      
          
    • 用概率作答。可以按业务需要移动阈值（第05章）。
      • 
          
    • 可解释。权重的符号和大小，直接说明“哪个特征往哪边推”（下图）。
      • 
          
    • 轻量。要记的数只有 特征数 + 1 个（多分类时再 × 类别数）。训练·预测都快。
      • 
          
    • 适合做基线。在用复杂模型之前，先拿它跑一遍的第一位应聘者。
      • 
        
    
      
    
      
    
        
    缺点
    
        
      
          
    • 边界是直线（平面）。像同心圆那样弯曲的边界，不变换特征就画不出来。
      • 
          
    • 无法自己构造特征之间的交互（如 长度 × 高度）。必须由人做好加进去。
      • 
          
    • 对单位敏感。标准化几乎是必需的。
      • 
          
    • 跟不上曲线关系。强度随龄期先快后慢地增长。需要人来构造 log(龄期) 这样的特征（第04章）。

    工作条件 · 常调的超参数（scikit-learn LogisticRegression）
    
    
      
    参数默认值含义与用法
    
      
        
    C1.0正则化强度的倒数。越小正则化越强（把权重压小）。方向与 5-3 岭回归的 alpha 相反。在这份数据上，0.1 以上的结果几乎相同（第05章）。
    
        
    l1_ratio (1.8+)
    penalty（1.7 及以下）    		0 (L2)正则化类型。0 = L2（与岭回归相同的惩罚，默认），1 = L1（与 Lasso 相同的惩罚，把无用的权重变为 0），介于两者之间 = Elastic Net。使用 L1 需要 solver="saga" 或 "liblinear"。
    
        
    solver"lbfgs"寻找损失谷底的方法。大多数情况下默认值就够了。数据非常大时用 "saga"。
    
        
    max_iter100迭代次数上限。出现“未收敛（ConvergenceWarning）”时调大，但先确认是否做了标准化。
    
        
    class_weightNone设为 "balanced" 时，会给数量少的类别的损失更大权重。在不合格只占百分之几的工艺数据中漏掉不合格时使用。
    
          
    
    
  
    
  
    
    
    
      C 与 alpha — 同一个旋钮，相反的刻度
      
      
    记作 C ≈ 1 / alpha。红色一侧表示“把权重压得很狠”。
    
    
    
    
    
      适合的工作 · 不适合的工作
      
    
        
    适合的工作需要概率的判定（合格概率、次品概率）、必须说明理由的判定（质量报告、客户投诉处理）、专家能提供好特征（如水胶比）的表格数据、快速的第一条基线
    
        
    不适合的工作边界严重弯曲的数据（同心圆、月牙形）、原始像素的图像（→ 深度学习系列）、特征间交互是关键而人又难以构造的问题
    
        
    补充RidgeClassifier 是另一位应聘者，它把答案变成 −1/+1，用岭回归求解。速度快，但不输出概率。

      主席博士今天的应聘者向我们展示了三点。
      • 给线性得分套上 Sigmoid函数就得到概率。名叫回归，干的是分类
      • 交叉熵对自信却答错的答案罚得最重。梯度下降用“错了多少 × 特征”来修正权重
      • 两个好特征（水胶比、log 龄期）能顶八个原始特征。阈值由业务根据错误的代价来定

      设定与注意事项
      关于本页数据、图片和设定的说明
      
  
      • 数据与计算。实操考题是 UCI 混凝土抗压强度数据 1,030 组，试卷是以 test_size=0.25、stratify=强度三档、random_state=42 划分出的 258 组。35MPa 的合格标准和 25·45MPa 的等级阈值是为教学设定的值。第01章、第04章、第05章、第06章以及面试结果中的数字，由本页在浏览器中直接训练计算得出（用梯度下降求解与 scikit-learn 相同的目标函数）。与 Colab 结果（A章）在小数点后第三位可能略有不同。第03章的“AI 给出的代码”是汇集常见错误刻意制作的示例，并非某个 AI 服务的真实回答。
      • 申请表·第1页。各集第00章的九格申请表是为本系列新绘制的。逻辑回归一集沿用了一张广为流传的九格总结信息图的结构（二分类 → 线性得分 → Sigmoid函数 → 概率 → 边界 → 阈值 → 损失 → 学习 → 多分类），没有搬用原图和标志。
      • 图片。登场人物的图片沿用自《人工智能算法家族组织图》。面试室场景、工牌和图表由本页用代码直接绘制。
      • “招聘委员会”设定。这是把模型比作应聘者、把训练和评估比作面试的比喻，并不代表真实的招聘流程或某家公司。不录用只表示“不适合这份工作”，并不是模型的优劣之分。
      • 登场人物。Money-Robo 是作者运营的服务的吉祥物角色。博士、助理、果蝇研究员、手册先生和应聘者均不代表真实人物。台词中关于钱和预算的说法，是比喻计算成本的口头禅。
      • 数据。监督学习本部的实操考题是 UCI Machine Learning Repository 的 Concrete Compressive Strength 数据（Yeh, 1998，1,030 组，CC BY 4.0）。各集统一的试卷划分为 test_size=0.25、stratify=强度三档、random_state=42（训练 772 · 试卷 258）。强度等级（25 · 45 MPa）和合格标准（35 MPa）是本系列为教学设定的阈值，不能代替任何设计标准。
      • 语言。本系列用韩语写成。译本（English · 中文 · 日本語 · Oʻzbekcha · Русский）在韩语版内容定稿后以相同文件名追加。Colab 代码中的注释和运行结果保留韩语原文。
