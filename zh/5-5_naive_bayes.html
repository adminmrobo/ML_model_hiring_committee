朴素贝叶斯 — 假装特征互不相识，把概率相乘

5-4 的逻辑回归用特征乘以权重相加得到的得分来给出概率。今天的应聘者反过来问：“如果是合格的配合比，出现这么多水泥的概率是多少？如果是不合格的呢？”

朴素贝叶斯为每个类别分别测好特征的分布，新配合比一来，就把先验概率 × 各特征似然相乘，比较属于哪个类别的概率更大（贝叶斯定理）。它故意假设特征之间互不影响。多亏这个天真的（naive）假设，训练只需统计均值和方差就结束了。

1. 贝叶斯定理 Bayes' Theorem

用“如果是 y，出现 x 的概率”反推看到证据 x 后属于类别 y 的概率。

P(y | x) = P(x | y) · P(y)P(x)
→ 01 自我介绍

2. 先验概率 Prior

看配合比之前就已知的：训练数据中各类别所占的比例。

P(y = 合格) = 377772
→ 02 实操考题

3. 似然 Likelihood

“如果是合格配合比，会出现这个值吗？”对每个类别，从一个特征的分布上读出高度。

→ 01 自我介绍

4. 朴素假设 Conditional Independence

假设一旦知道类别，特征之间就不再相互提供任何信息。所以直接相乘即可。

P(x₁, x₂, …, xₙ | y) ≈ P(x₁|y) · P(x₂|y) ⋯ P(xₙ|y)
→ 05 绩效考核（假设被打破之处）

5. 高斯似然 Gaussian Likelihood

把每个连续值特征在各类别中都看作钟形（正态分布），只记住均值 μ 和方差 σ²。

P(xᵢ | y) = 1√(2πσ²) exp(− (xᵢ − μ)²2σ²)
→ 01 自我介绍

6. 用对数之和代替乘积 Log-Probabilities

把很小的概率连乘多次会趋近于 0。取对数后相加，就相当于为每个特征累加证据得分。

log P(y|x) = log P(y) + Σi log P(xᵢ|y) + 常数
→ 01 自我介绍

7. 后验概率与判定 Posterior & Decision

比较两个类别的后验概率，选较大的一方。概率被调整为总和等于 1。

ŷ = argmaxy P(y) Πi P(xᵢ | y)
→ 05 绩效考核

没有梯度下降。扫一遍训练数据，统计各类别的比例、均值和方差。

证据账本 · 用八个特征审查一个配合比（从训练配合比中选取）

用大白话说贝叶斯定理

“水泥 380kg 的配合比合格的概率”很难直接数出来，因为正好 380kg 的配合比几乎没有。反过来却很容易。先画出合格配合比的水泥分布，就能读出“如果是合格配合比，出现 380kg 合不合理”（似然）。再乘上“合格配合比本来有多常见”（先验概率），比较两个类别即可。

后验概率 ∝ 先验概率 × 似然
P(合格 | x) ∝ P(合格) × P(x | 合格)

为什么叫“朴素”

有八个特征时，就得测“合格配合比中水泥 380kg、同时水 160kg、同时龄期 28 天的概率”。这样的组合在数据中几乎不存在。所以朴素贝叶斯假设一旦知道类别，特征之间就相互独立，把八个似然分别测出来再相乘。计算变简单了，但如果有实际纠缠在一起的特征（如水和高效减水剂），就会把同一证据数两遍（第05章）。

P(x₁,…,x₈ | 合格) ≈ P(x₁|合格) × ⋯ × P(x₈|合格)

与逻辑回归（5-4）有什么不同

逻辑回归调整权重，直接去拟合“合格的概率”（判别模型）。朴素贝叶斯先描绘“每个类别的数据长什么样”，再用贝叶斯定理倒过来求概率（生成模型）。上面证据账本中柱子的长度，作用类似逻辑回归的“权重 × 特征”，但朴素贝叶斯是从分布的形状来确定这个长度的。分布与实际不符，柱子长度也会跟着出错。

偏度是分布偏向一侧的程度（钟形时接近 0）。为 0 的配合比很多、或取值只有几个的特征，离钟形很远。这张表预先告诉了你第05章的判定。

这次不需要标准化

对 5-4 逻辑回归和 5-1 KNN 来说，标准化几乎是必需的。朴素贝叶斯每个特征单独测均值和方差，所以即使把水泥从 kg 改成吨，两个类别的钟形也只是按同样比例伸缩。似然的比值不变。

    ④ 版本备忘 — 这位应聘者的问题不在版本，而在“类型”
    
    
    GaussianNB 的参数多年未变。只有两个：priors（亲自设定先验概率）和 var_smoothing（为防止方差为 0 而加上的小值，默认 1e-9 × 最大特征方差）。比版本更常出错的是类型。MultinomialNB·ComplementNB 接收词频这类非负计数，BernoulliNB 接收 0/1，CategoricalNB 接收类别编号。即使放进连续值，大多也不会报错（MultinomialNB 只在有负数时才报错）。有分数不代表模型选对了。
    
    
    MultinomialNB·BernoulliNB 等的 alpha（拉普拉斯平滑），在 1.2 新增了 force_alpha 参数，从 1.4 起默认值改为 True。使用非常小的 alpha 时结果可能因版本而异，所以第一行要用 print(sklearn.__version__) 打印版本。A章的 Colab 代码只用 GaussianNB，并一并附上运行结果。

    读一组时发生的事
    
      
    读一组配合比，只更新该配合比所属类别的账本。个数加 1，均值移动“（新值 − 旧均值）÷ 个数”，方差也用同样的方式更新（Welford算法）。全部读完后，个数的比例就成为先验概率。不需要像梯度下降那样转几百圈。用同样的方法，每来一组新配合比都可以接着学习（partial_fit）。
    
      
    n ← n + 1  ·  μ ← μ + (x − μ) / n
    M ← M + (x − μ旧)(x − μ新)  ·  σ² = M / n

    为什么预测不了强度（MPa）— 专做分类的原因
    
      
    朴素贝叶斯“按类别”测量特征的分布。若把强度本身当作类别，不同的强度值有 845 个，每个类别只有一两组配合比。只有一组就量不出方差，没见过的强度值（如 41.37MPa）更是根本选不出来。把强度按区间划分（三档）就变成了分类，但那已经不是预测 MPa 的回归了。所以这位应聘者没有参加回归考题。
    
    
    
    
    
      适合的工作 · 不适合的工作
      
    
        
    适合的工作文档·邮件分类（词频，MultinomialNB）、特征多而数据少的工作、数据不断进来需要随时更新的工作、在复杂模型之前 1 分钟就能跑完的基线
    
        
    不适合的工作特征强烈纠缠的配合比数据（水·减水剂·骨料）、确实需要良好校准概率的判定、预测数值本身的回归
    
        
    复试条件带着修整好的特征（水胶比、log 龄期）回来，就能以 81.0% 超过录用线（见面试结果中的复查）。这是一位需要人帮它调好分布形状的员工。
    
      
    
    
    
  
    
  
    
    工作条件 · 常调的超参数（scikit-learn GaussianNB）
    
    
      
    参数默认值含义与用法
    
      
        
    priorsNone（训练数据比例）亲自设定先验概率：数量与类别数相同、总和为 1 的一组数。现场的实际次品率与训练数据不同时使用。效果与移动判定阈值相同（第05章 先验概率旋钮）。
    
        
    var_smoothing1e-9用这个值乘以最大的特征方差，加到所有方差上。防止某个类别中某特征的值全部相同、方差为 0 时计算崩溃。调大会让钟形变宽、判定变迟钝。用交叉验证来挑。
    
          
    
    
  
    
  
    
    家族介绍 · 选择与数据形状相符的朴素贝叶斯（申请表第9格）
    
    
      
    类特征的形状似然主要参数 · 用途
    
      
        
    GaussianNB连续值正态分布（均值·方差）var_smoothing · 传感器数值、配合用量 — 本次面试
    
        
    MultinomialNB非负计数多项分布（各词比例）alpha · 文档分类的经典基线
    
        
    ComplementNB非负计数用“不属于该类别的一方”的分布来测alpha · 类别比例失衡的文档分类
    
        
    BernoulliNB0/1（有·无）伯努利分布alpha、binarize · 短文本、检查清单项目
    
        
    CategoricalNB类别编号各类别的频数alpha、min_categories · 工厂名称、原材料等级

      设定与注意事项
      关于本页数据、图片和设定的说明
      
  
      • 数据与计算。实操考题是 UCI 混凝土抗压强度数据 1,030 组，试卷是以 test_size=0.25、stratify=强度三档、random_state=42 划分出的 258 组。35MPa 的合格标准和 25·45MPa 的等级阈值是为教学设定的值。第01章、第02章、第04章、第05章、第06章以及面试结果中的数字，全部由本页在浏览器中直接训练计算得出（与 scikit-learn GaussianNB 相同的公式：各类别均值·方差，var_smoothing 1e-9，先验概率 = 训练比例）。这是没有迭代的闭式公式，所以与 Colab 结果（A章）数字相同。预先算好放入的值只有第03章找错练习中 MultinomialNB 的准确率（77.1%·66.3%）一项，取自 A章第6格的运行结果。第03章的“AI 给出的代码”是汇集常见错误刻意制作的示例，并非某个 AI 服务的真实回答。应聘者朴素贝叶斯专做分类，所以没有参加回归考题（R²）。
      • 申请表·第1页。各集第00章的九格申请表是为本系列新绘制的。逻辑回归一集沿用了一张广为流传的九格总结信息图的结构（二分类 → 线性得分 → Sigmoid函数 → 概率 → 边界 → 阈值 → 损失 → 学习 → 多分类），没有搬用原图和标志。
      • 图片。登场人物的图片沿用自《人工智能算法家族组织图》。面试室场景、工牌和图表由本页用代码直接绘制。
      • “招聘委员会”设定。这是把模型比作应聘者、把训练和评估比作面试的比喻，并不代表真实的招聘流程或某家公司。不录用只表示“不适合这份工作”，并不是模型的优劣之分。
      • 登场人物。Money-Robo 是作者运营的服务的吉祥物角色。博士、助理、果蝇研究员、手册先生和应聘者均不代表真实人物。台词中关于钱和预算的说法，是比喻计算成本的口头禅。
