1. 곡선 관계 Non-linear Relationship

강도는 재령에 따라 처음엔 빨리, 나중엔 천천히 오른다. 직선은 이 휘어짐을 못 따라간다.

→ 02 실기 과제지

2. 다항 특징 Polynomial Features

특징 x를 x², x³으로 늘린다. 모델은 여전히 가중치를 곱해 더하는 선형 회귀다.

ŷ = w1x + w2x2 + w3x3 + b
→ 01 자기소개

3. 특징 폭발 Feature Explosion

특징이 여럿이면 거듭제곱에 서로 곱한 항(x₁x₂)까지 붙는다. 차수를 올리면 빠르게 불어난다.

특징 수 = C(8 + d, d) − 1
d = 차수, 8 = 원래 특징 수, −1 = 상수 열
→ 02 실기 과제지

4. 최소제곱 Least Squares

잔차(정답 − 예측)의 제곱합을 가장 작게 하는 가중치를 찾는다. 5-2 선형 회귀와 같은 방법이다.

최소화  Σ (yi − ŷi)2
→ 04 수습 기간

5. 과대적합 Overfitting

차수를 올리면 훈련 점수는 계속 오르지만, 처음 보는 데이터의 점수는 어느 순간 무너진다.

→ 05 성과 평가

6. 릿지 (L2) Ridge Regression

가중치 제곱합에 벌점을 준다. 모든 가중치를 0 쪽으로 고루 줄인다(0이 되지는 않는다).

Σ(y − ŷ)2 + α Σ wj2
→ 04 수습 기간

7. 라쏘 (L1) Lasso Regression

가중치 절댓값 합에 벌점을 준다. 쓸모가 적은 가중치를 아예 0으로 지운다(특징 선택 효과).

12nΣ(y − ŷ)2 + α Σ |wj|
→ 04 수습 기간

8. 엘라스틱넷 Elastic Net

L1과 L2를 비율 ρ(l1_ratio)로 섞는다. 지우기도 하고, 서로 닮은 특징을 함께 남기기도 한다.

… + α [ ρ Σ|w| + 1 − ρ2 Σw2 ]
→ 05 성과 평가

9. α 고르기 Choosing α (Cross-Validation)

α가 작으면 과대적합, 크면 과소적합. 시험지가 아니라 훈련 데이터 안의 교차 검증으로 고른다.

α가 클수록 규제가 세다. 로지스틱 회귀·SVM의 C는 반대 방향이다(C ≈ 1/α).
→ 05 성과 평가

Self-introduction · Concept

자기소개 — 특징을 늘려 곡선을 긋고, 고삐로 잡는다

특징 x → x, x², x³, … → 선형 회귀 → 규제 α로 가중치를 누른다

λ
지원자 · 다항 회귀와 규제저는 직선만 긋는 선형 회귀에게 재료를 더 줍니다. x 옆에 x²와 x³을 붙여 주면 똑같이 "곱해서 더하기"만 해도 곡선이 됩니다. 다만 재료가 너무 많으면 점 하나하나를 따라가느라 몸을 비틉니다. 그때 α가 고삐를 당깁니다.
직접 만져 보기 · 물-결합재비 하나로 28일 강도를 (훈련 배합 12건으로 일부러 줄인 장난감 문제)

다항 회귀도 "선형" 회귀다

곡선을 그리는데 왜 선형일까? 모델이 하는 일은 여전히 특징마다 가중치를 곱해 더하는 것뿐이다. 바뀐 것은 특징 쪽이다. x 대신 [x, x², x³]을 넣었을 뿐이다. 가중치에 대해 선형이라서 5-2 선형 회귀의 최소제곱 방법을 그대로 쓴다. 특징이 여럿이면 x₁·x₂처럼 서로 곱한 상호작용 항도 붙는다. "시멘트가 많을 때 재령의 효과가 더 크다" 같은 관계를 이 항이 맡는다.

ŷ = w₁x + w₂x² + w₃x³ + b  ← w에 대해 선형

규제는 벌점이다

최소제곱은 훈련 오차만 본다. 특징이 많으면 아주 큰 가중치들이 서로 상쇄하며 점 하나하나를 지나가는 곡선을 만든다. 규제는 손실에 "가중치가 크면 벌점"을 더한다. α가 그 벌점의 세기다. α = 0이면 규제가 없고, α가 크면 가중치가 0 쪽으로 눌려 곡선이 펴진다. 너무 크면 직선보다도 못한 평평한 선이 된다(과소적합).

손실 = 오차² 합 + α × (가중치 크기)

위 그림에서 볼 것

차수를 1 → 3으로 올리면 곡선이 점들의 휘어짐을 따라간다. 10까지 올리고 α를 0으로 두면 곡선이 검은 점(훈련) 사이에서 위아래로 출렁이고, 회색 점(시험)에서 크게 빗나간다. 훈련 R²는 오르는데 시험 R²는 음수로 떨어진다. 이것이 과대적합이다. 이제 차수는 10에 둔 채 α만 올려 보자. 곡선이 차분해지고 시험 R²가 돌아온다. 이 면접 전체가 이 그림 하나를 콘크리트 데이터 전체(특징 8개, 164개)로 키운 것이다.

한 줄이 배합 하나(샘플), 배합량과 재령이 특징(X), 압축 강도(MPa)가 타겟(y)이다

본시험 · 회귀

압축 강도(MPa)를 맞힌다

합격/불합격 이름표가 아니라 강도 숫자 그 자체를 맞힌다. 성적은 R²(1이면 완벽, 0이면 "늘 평균"과 같음, 음수면 그보다 못함)와 MAE(평균 몇 MPa 틀리나)로 잰다. 늘 훈련 평균을 답하는 기준선은 시험 MAE 13.52MPa, R² 0이다.

합격선 · 매뉴얼 씨의 현장 경험식

R² 0.735 · MAE 6.72MPa

매뉴얼 씨는 학습하지 않는다. 교과서의 에이브럼스 식으로 28일 강도를 내고, 재령 보정식으로 날짜를 맞춘다. 사람의 지식만으로 이만큼 맞힌다. 물-결합재비 대신 물-시멘트비를 넣으면 R²가 0.058로 무너진다. 슬래그·플라이 애시도 굳는다는 지식이 들어가야 식이 맞는다.

f₂₈ = 96.5 / 7(물-결합재비) MPa  ·  f(t) = f₂₈ · t / (4 + 0.85t)
그림 · 축을 골라 보기 (색 = 강도 등급, 속이 빈 점 = 봉인된 시험지)
기본 그림은 재령(가로, 로그 눈금 아님)과 강도(세로)다. 처음 28일까지 가파르게 오르고 그 뒤로 완만해지는 휘어짐이 보인다. 직선 하나로는 이 모양을 못 따라간다(지원서 1번 칸).

파란 머리글이 특징(X), 빨간 열이 타겟(y)이다. 5-4 분류팀은 같은 강도를 35MPa 문턱에 대어 이름표로 바꿔 썼다. 같은 데이터, 다른 질문이다. "봉인" 표시가 붙은 258줄은 05장에서 한 번만 연다. 맨 오른쪽 열은 매뉴얼 씨의 경험식이 낸 예측이다.

왜 두 번 표준화하나

먼저 원래 특징 8개를 표준화한다(평균 0, 표준편차 1). 그대로 거듭제곱하면 굵은 골재 1,000kg의 세제곱은 10억이 되고 고성능 감수제는 몇십이 되어, 숫자 크기 차이가 걷잡을 수 없다. 다항 특징을 만든 뒤 한 번 더 표준화한다. 규제는 "가중치 크기"에 벌점을 주므로, 열마다 단위가 다르면 벌점이 불공평해진다. 두 번 모두 평균과 표준편차는 훈련 데이터로만 구한다.

원 특징 → 표준화 → 다항 특징 (164개) → 표준화 → 릿지 · 라쏘 · 엘라스틱넷

데이터 교체 안내 — 내 공장 데이터로 바꾸려면

  • 표 형식(CSV 등)으로, 한 줄에 배합(또는 로트) 하나, 맞히려는 숫자 열 하나가 있으면 된다.
  • Colab 코드(A장) 1번 칸의 데이터 읽기와 FEATURES 두 곳만 바꾼다. 매뉴얼 씨의 경험식(3번 칸)은 내 업무의 경험식이나 기존 계산표로 바꾼다.
  • 특징이 20개만 넘어도 3차 다항 특징은 1,770개다. 배합 수보다 특징이 많아지면 규제 없이는 풀리지 않는다. 2차부터 시작한다.
  • 글자로 된 특징(공장, 원자재 등급)은 원-핫 인코딩으로 숫자 열로 바꾼다. 원-핫 열을 거듭제곱해도 같은 값이라 상호작용 항만 뜻이 있다(interaction_only).
  • 강도 범위 밖의 배합(아주 낮은 물-결합재비 등)은 다항 곡선이 크게 빗나가기 쉽다. 데이터 범위를 기록해 두고 그 밖에서는 쓰지 않는다.

    Probation · Training
    
    
    수습 기간 — 고삐를 풀어 가며 가중치가 자라는 모습
    
    
    3차 다항 특징 164개 · α를 크게 → 작게 재생 · 라쏘는 좌표 하강으로 한 바퀴씩
    
  
    
  
    
    움직이는 그림 · 3차 다항 회귀의 가중치 164개 (훈련 배합 772건, 브라우저에서 계산)
    
    
      
    
    
    
    
    
    
    
    
    
      
      
      
      
    
    
    
    계산 준비 중…
    
    
    재생은 α = 100에서 시작해 0.001까지 내려간다. 각 α에서 앞 α의 답을 출발점으로 다시 푼다(웜 스타트). "좌표 하강 한 바퀴"는 라쏘·엘라스틱넷에서 가중치를 모두 0에 두고 지금 α로 한 바퀴(164개를 하나씩)씩 고친다. 릿지는 한 번에 풀리므로 한 바퀴가 곧 끝이다. 아래 선 그림의 시험 R²는 설명용으로 보여 줄 뿐, α를 고르는 데 쓰면 반칙이다(05장 교차 검증).
    
  
    
  
    
    
    
      
    릿지는 한 번에 푼다 — 닫힌 해
    
      
    오차 제곱합에 α·Σw²를 더한 손실은 매끈한 그릇 모양이라, 바닥을 식 하나로 바로 구한다. 5-2 선형 회귀의 정규방정식에 대각선으로 α를 더한 것이다. 이 α 덕분에 특징끼리 거의 같은 정보를 담아(조건수가 커서) 풀이가 흔들릴 때도 답이 안정된다. 이것이 1970년에 릿지가 처음 나온 까닭이다.
    
      
    w = (XᵀX + αI)⁻¹ Xᵀy
    
    
    
    
    
      
    라쏘는 하나씩 고친다 — 좌표 하강
    
      
    절댓값 |w|는 0에서 뾰족해 식 하나로 못 푼다. 그래서 가중치를 하나씩 돌아가며 고친다. j번째 가중치만 움직인다고 보면 답은 "다른 가중치로 설명하고 남은 몫(ρⱼ)"을 α만큼 깎은 값이다. 남은 몫이 α보다 작으면 정확히 0이 된다. 이 깎기를 소프트 임계값이라 부른다. 164개를 한 바퀴 돌고, 더 바뀌지 않을 때까지 반복한다.
    
      
    wⱼ ← S(ρⱼ, α) = sign(ρⱼ) · max(|ρⱼ| − α, 0)
    
    
    
  
    
  
    
    
    예산 담당 주판봇라쏘는 마음에 들어. α = 0.1이면 164개 중 98개를 0으로 지우니까 외울 숫자가 66개(+ 절편)로 줄잖아. 릿지는 하나도 안 지우고 다 조금씩 깎기만 하고.

    06
    
    
    Personnel card · Conclusion
    
    
    인사 카드 — 어디에 배치하고 어떻게 부리나
    
    
    강점과 약점, 맞는 일과 안 맞는 일, 근무 조건(하이퍼파라미터)
    
  
    
  
    
    
    
      
    λAPP-03 → EMP-0003다항 회귀와 규제지도 본부 › 회귀팀
    
      
    한 줄 평: 재료를 늘려 곡선을 긋고, 고삐로 다스리는 선형 회귀. 차수와 α 두 손잡이만 잘 잡으면 경험식을 넘는다. 손잡이를 놓으면 폭주한다.
    
    
    
    
    
      
    
        
    강점
    
        
      
          
    • 곡선과 상호작용을 잡는다. 사람이 log(재령)이나 물-결합재비를 만들어 주지 않아도 3차 항들이 휘어짐을 흉내 낸다(R² 0.567 → 0.849).
      • 
          
    • 여전히 선형 회귀다. 학습이 빠르고(릿지는 식 하나), 같은 입력이면 늘 같은 답이다.
      • 
          
    • 규제로 안전장치를 단다. 릿지는 불안정한 풀이를 안정시키고, 라쏘는 쓸모가 적은 항을 지워 모델을 가볍게 한다.
      • 
          
    • 다른 지원자의 재료가 된다. 다항 특징 + 로지스틱 회귀, 다항 커널 SVM(5-8)이 같은 생각을 쓴다.
      • 
        
    
      
    
      
    
        
    약점
    
        
      
          
    • 특징이 폭발한다. 특징 8개 4차면 494개, 20개 3차면 1,770개다. 배합 수보다 많아지면 규제 없이는 못 푼다.
      • 
          
    • 데이터 범위 밖에서 날뛴다. 거듭제곱은 범위를 조금만 벗어나도 값이 크게 뛴다. 4차의 폭주가 바로 이것이다.
      • 
          
    • 설명이 어려워진다. "재령²·시멘트" 같은 항의 가중치는 사람이 읽기 어렵다. 라쏘가 지워도 남은 항이 원인이라는 뜻은 아니다.
      • 
          
    • 손잡이가 둘이다. 차수와 α를 함께 골라야 하고, 둘 다 교차 검증이 필요하다.
      • 
        
    
      
    
    
    
  
    
  
    
    라쏘가 남긴 항 · 3차 다항 특징 164개 중 0이 아닌 가중치 (표준화한 특징 기준, 큰 순서로 12개)
    
    
    
    
    
    
  
    
  
    
    근무 조건 · 자주 만지는 하이퍼파라미터 (scikit-learn)
    
    
      
    인자기본값뜻과 쓰는 법
    
      
        
    PolynomialFeatures(degree)2차수. 2부터 시작해 교차 검증으로 올린다. 이 데이터에서는 3차가 가장 좋았고, 4차는 규제 없이는 폭주했다(05장).
    
        
    include_biasTrue상수 열(1)을 만들지 여부. 뒤에 오는 회귀 모델이 절편을 따로 두므로 False로 둔다. True면 3차 특징이 165개로 세어진다.
    
        
    interaction_onlyFalseTrue면 x²·x³ 없이 서로 곱한 항(x₁x₂)만 만든다. 원-핫 특징처럼 제곱해도 같은 열에 쓴다.
    
        
    alpha (Ridge·Lasso·ElasticNet)1.0규제 세기. 클수록 세다. 로지스틱 회귀·SVM의 C와 방향이 반대다(C ≈ 1/α). RidgeCV·LassoCV·ElasticNetCV가 교차 검증으로 고른다.
    
        
    l1_ratio (ElasticNet)0.5L1의 비율 ρ. 1이면 라쏘, 0에 가까우면 릿지. 서로 닮은 특징이 많으면 0.5 근처가 둘을 함께 남긴다.
    
        
    max_iter, tol (Lasso·ElasticNet)1000, 1e-4좌표 하강의 반복 상한과 멈춤 기준. 작은 α에서 ConvergenceWarning이 뜨면 max_iter를 늘린다.
    
          
    
    
  
    
  
    
    
    
      α와 C — 같은 손잡이, 반대 눈금
      
      
    C ≈ 1/α로 기억한다. 빨간 쪽이 "가중치를 세게 누른다"다. 5-4 로지스틱 회귀의 03장 틀린 곳 찾기에 이 방향 실수가 나온다.
    
    
    
    
    
      맞는 일 · 안 맞는 일
      
    
        
    맞는 일특징이 몇 개~몇십 개인 표 데이터에서 휘어진 관계와 상호작용을 잡을 때(배합 → 강도, 온도·압력 → 수율), 경험식을 데이터로 다듬을 때, 빠르고 늘 같은 답이 필요한 예측
    
        
    안 맞는 일특징이 수백 개 이상인 데이터(다항 특징이 폭발한다), 학습 범위 밖을 예측해야 하는 일(외삽), 계단처럼 꺾이는 관계(→ 결정 트리 5-6), 이미지·소리 같은 날것 데이터
    
        
    덧붙임라쏘는 "규제"다. 쓸모가 적은 항을 지우는 결과로 특징을 고르지만, 물-결합재비처럼 뜻 있는 새 특징을 만들어 주지는 않는다(특징공학은 사람의 몫). 5-2에서 특징 8개에 사람이 만든 특징 두 개(물-결합재비, log 재령)를 더해 낸 R² 0.842(외울 숫자 11개)와 3차 164개로 낸 0.849가 거의 같다.
