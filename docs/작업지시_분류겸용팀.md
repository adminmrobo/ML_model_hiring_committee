## 편별 이야기 (권장)
- **5-5 나이브 베이즈 (지도 › 분류팀, 기호 P)**: "특징끼리 독립이라 치고 확률을 곱한다". 가우시안 분포를 특징마다 그려 보이고(합격·불합격 두 종 모양 곡선), 베이즈 정리(사전 확률 × 가능도). 학습 = 평균·분산 세기(주판봇이 좋아함). 판정: 70.9% → **보류**. 까닭: 시멘트·슬래그·물 등이 서로 얽혀 있어 "독립" 가정이 깨짐 + 재령의 분포가 종 모양이 아님(1·3·7·28·…일로 띄엄띄엄). alts: 물-결합재비·log 재령 추가 81.0%(합격), 3등급 58.1%, 사전 확률 바꾸기. 회귀는 하지 않는다(분류 전용) — 왜 회귀를 못 하는지도 짚는다.
- **5-6 결정 트리 (지도 › 겸용팀, 기호 T)**: 스무고개. 매뉴얼 씨의 순서도를 데이터가 직접 만든다(0편과 연결 — 깊이 1 나무 = 문턱 하나). 지니 불순도/엔트로피, 회귀 트리(잎 = 평균, 계단 예측선, MSE로 자르기). 깊이 슬라이더로 과대적합(분류 훈련 99.9 vs 시험 92.6, 회귀 깊이 4는 0.662로 보류지만 끝까지 키우면 0.891), 가지치기(max_depth, min_samples_leaf, ccp_alpha). 판정 기준 모델을 분명히 정한다(예: 기본 설정 = 끝까지 키운 나무 → 분류 92.6 합격·회귀 0.891 합격, alts에 깊이 4 → 회귀 보류). 9편 GBM이 분류에서도 회귀 나무를 쓴다는 예고.
- **5-7 랜덤 포레스트 (지도 › 겸용팀, 기호 RF, 앙상블 배지)**: 부트스트랩 + 특징 무작위 → 서로 다른 나무들의 다수결/평균. 나무 1그루 84.9 → 10그루 92.2 → 100그루 93.4(흔들림이 줄어드는 그림: 다시 뽑기 버튼). OOB 점수, 특징 중요도(시멘트·재령이 1·2위 — 매뉴얼 씨의 지식과 비교), Extra Trees 덧붙임. 판정: 분류 93.4 / 회귀 0.927 합격. 예산 담당: 나무 100그루 = 학습·예측 비용. 패밀리 4-10 앙상블 계보로 링크.
- **5-8 SVM (지도 › 겸용팀, 기호 SV)**: 가장 넓은 길(마진), 서포트 벡터, 소프트 마진 C(로지스틱 C와 같은 방향 — 5-4와 연결), 커널 트릭(RBF: 공간을 휘는 마술 — 박사 magic), γ. SVR의 ε 띠. 표준화 필수. 판정: SVC RBF C=10 88.0%(또는 정한 기준), SVR C=100 0.907 합격. 브라우저에서는 2특징 시연(물-결합재비·log 재령)으로 경계·서포트 벡터를 그리고, 8특징 결과는 Python 사전 계산 또는 간단한 커널 근사(무작위 푸리에 특징)로 — 어느 쪽인지 밝힌다.
- **5-9 GBM (지도 › 겸용팀, 기호 GB, 앙상블 배지)**: 얕은 나무를 차례로 덧대며 "아직 틀린 만큼(잔차)"을 배운다. 학습률 × 나무 수의 균형, 조기 종료(검증 점수), 과대적합. 회귀 덧대기 재생(10 → 100 → 300그루: R² 0.640 → 0.927 → 0.949). 분류도 내부는 회귀 나무(로그 오즈 잔차). HistGradientBoosting, XGBoost·LightGBM·CatBoost는 "같은 원리의 빠르고 튼튼한 구현"으로 설명(코드는 scikit-learn만). 판정: 합격(회귀 1위권). 지원자 다섯 명(5-5~5-9)을 한 표로 비교하는 짧은 "중간 정산" 카드를 06장에 넣는다.
