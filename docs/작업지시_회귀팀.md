## 데이터와 규정 (확인된 숫자, 시험지 고정 나누기)
- 콘크리트 1,030건, train_test_split(test_size=0.25, stratify=강도 3등급(25·45MPa), random_state=42) → 훈련 772 / 시험 258. JS에서는 concRows()의 test 플래그.
- 기준선(늘 훈련 평균): 시험 MAE 13.52MPa, R² ≈ 0.
- **회귀팀 매뉴얼 씨 = 현장 경험식(사람의 지식, 학습 없음)**: 28일 강도 f28 = 96.5 / 7^(물-결합재비) MPa (에이브럼스 식, 교과서 상수 A=14,000psi≈96.5MPa, B=7, 물-시멘트비 대신 물-결합재비로 확장), 재령 보정 f(t) = f28 · t / (4 + 0.85t) (ACI 209R, 습윤 양생 보통 시멘트). → 시험 **R² 0.735, MAE 6.72MPa = 회귀팀 합격선**. (물-시멘트비로 쓰면 R² 0.058 — 혼화재 지식이 없으면 무너진다.)
- 분류 합격선(5-0 매뉴얼 씨, 35MPa 합격 여부): 76.7% (PASSLINE).
- 회귀 판정 규칙: 시험 R²가 합격선 0.735보다 크고 기준선보다 크면 합격, 아니면 보류. MAE도 함께 보여 준다.

## 편별 이야기 (권장)
- **5-1 KNN (지도 › 입문팀, 사원증 기호 k)**: "가까운 배합 k개에게 묻는다". 같은 이웃으로 평균 내면 회귀(KNR), 다수결이면 분류(35MPa) — 0편의 "같은 데이터, 다른 질문"을 한 지원자가 다 한다. 핵심 장면: **표준화 전후로 이웃이 바뀐다**(굵은 골재 1,000kg vs 재령 몇 일 — 고른 배합의 이웃 5개를 표준화 전/후로 보여 주기). 판정: 표준화 안 하면 회귀 R² 0.716 → 보류, 표준화하면 0.767 → 합격(아슬아슬). 분류는 85.7%로 합격. k 슬라이더(과대/과소적합), 거리 가중. "학습"이 없다(외우기만 한다) — 수습 기간은 "k와 거리 고르기"로 보여 준다. 예산 담당: 학습 비용 0, 대신 예측할 때마다 772건 전부와 거리 계산(외울 숫자 = 데이터 전체). 지원서 1장 9칸 예: 1 이웃에게 묻기 2 거리(유클리드) 3 표준화 4 k개 고르기 5 다수결(분류) 6 평균(회귀) 7 k의 영향 8 거리 가중 9 차원의 저주/비용.
- **5-2 선형 회귀 (지도 › 회귀팀, 기호 β)**: 최소제곱 직선(평면). 잔차, MAE·RMSE·R², 정규방정식 vs 경사 하강, 가중치 해석. 핵심 장면: 특징 8개 그대로면 R² 0.567로 매뉴얼 씨의 경험식에 진다(보류) — 강도와 재령은 곡선 관계라서. 물-결합재비와 log(재령)을 넣으면 0.842로 이긴다("좋은 특징" — 5-4와 같은 교훈, 회귀 버전). 판정(기본 조건 = 특징 8개): 보류, alts에서 특징 추가 → 합격. 잔차 그림에 무늬(재령 축)로 곡선 관계를 들킨다.
- **5-3 다항 회귀와 규제 (지도 › 회귀팀, 기호 λ)**: 특징을 늘려 곡선을 그린다(PolynomialFeatures). 2차 0.806 → 3차 0.849 → 4차 폭주(−6.18, 훈련 0.982): 과대적합을 눈으로. 규제 3형제: Ridge(줄인다), Lasso(0으로 지운다 = 특징 선택, 하지만 특징공학이 아니라 규제다), Elastic Net(섞는다). 4차 + Ridge로 폭주가 잡히는지 직접 계산해 보여 준다. α 슬라이더로 가중치 막대가 줄고 0이 되는 모습. 로지스틱 회귀의 C와 방향이 반대(C ≈ 1/α) — 5-4로 링크. 판정: 3차(또는 규제한 모델) 합격.
- 지원서 1장은 5-4의 첨부 이미지 양식(제목 띠 "K-Nearest Neighbors" 등 영문 + 한글 부제, 3×3 칸, 굵은 번호 제목, 짧은 설명, 직접 그린 SVG, 연파랑 수식 상자)을 그대로 따른다. 그림은 모두 새로 그린다.
