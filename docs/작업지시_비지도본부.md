## 이 묶음에서 달라지는 것
- `meta.json`에 `"data": "digits"`를 꼭 넣는다(그래야 빌드가 손글씨 데이터를 싣는다). 콘크리트 데이터도 함께 실리지만 쓰지 않아도 된다.
- 구성은 같고 이름만 비지도에 맞춘다: 02 실기 과제지(정답 없는 1,797장, 숫자 그림 격자, "채점 봉투"), 05 성과 평가 = "채점 봉투 열기"(ARI·NMI 등 숨긴 정답과 비교) + 정답 없이 재는 점수(실루엣, 관성/엘보, BIC, 설명된 분산 등 그 모델에 맞는 것) + **업무 점수**: "묶음마다 대표 한 장에만 이름을 붙이면 전체 몇 %가 맞게 이름 붙나"(군집의 순도·대표 라벨 전파 정확도). 이것이 라벨링 비용 절감 이야기다.
- 판정(Interview): 군집팀은 ARI > 0.108이고 무작위(≈0)보다 크면 합격. 차원축소팀은 2D 지도 5-NN 정확도 > 18.1%면 합격. 기본 설정으로 판정하고, alts로 조건을 바꿔 보여 준다.
- code.py: `from sklearn.datasets import load_digits`(인터넷 필요 없음). UMAP은 `try: import umap except ImportError: subprocess pip install -q umap-learn`. 셀 구분 `# ------`, 주석 한국어. 정답(y)은 채점 칸에서만 쓴다는 것을 코드 주석으로 분명히 한다.
- 브라우저 계산: K-Means·GMM·PCA·DBSCAN·계층적 군집(NN-chain 또는 1,797×1,797 거리, 느리면 시연용 부분 표본)은 직접 구현할 수 있다. t-SNE·UMAP처럼 무거운 것은 Python으로 미리 계산해 `data.js`에 넣고 foot에 밝힌다(t-SNE는 작은 표본으로 브라우저 재생을 보여 주면 좋다). 무엇이 브라우저 계산이고 무엇이 미리 계산한 값인지 정직하게 적는다.
- 연출: 컨셉 문서 11장 표의 편별 무대·히어로 연기·3컷·반응·마무리 장면 그림을 따르고, 10장 규칙(기본이 아닌 표정 6가지 이상, data-move, 반응 표정·동작)도 지킨다.

## 편별 이야기 (권장)
- **5-10 K-Means (군집팀, μ)**: 중심 k개 → 가까운 중심에 배정 → 평균으로 중심 이동 반복(재생). 중심 그림이 "평균 글씨"로 보인다(10개 중심을 8×8로 그리기). 엘보(관성)·실루엣으로 k 고르기. 표준화가 KNN(5-1)에서는 약이었지만 여기선 독(0.666 → 0.468) — 왜인지. 초기값 운(n_init), K-Medoids 덧붙임. 판정: 합격.
- **5-11 계층적 군집 (군집팀, H)**: 가장 가까운 둘부터 합치는 덴드로그램, 연결 방식 4가지(ward 0.794 / single 0.000 사슬 효과), 자르는 높이 = 묶음 수. 예측(새 글씨 배정)이 없다는 점. 판정: 기본(ward) 합격, alts에 single(보류).
- **5-12 DBSCAN (군집팀, ε)**: 촘촘한 곳 = 묶음, 외톨이 = 잡음. eps·min_samples 민감도, k-거리 그래프로 eps 고르기(정답 없이). 묶음 수를 미리 안 정한다. 64차원에서 밀도가 희박해지는 문제(차원의 저주). 판정 기준 모델과 결과는 직접 정하고(예: k-거리로 고른 eps), 잡음 비율도 업무 점수에 반영해 정직하게 판정한다.
- **5-13 GMM (군집팀, N)**: K-Means의 확률 버전 — 종 모양 여럿의 혼합, 묶음마다 소속 확률(애매한 글씨는 반반), EM 재생, 공분산 형태(full/diag/spherical), BIC로 k 고르기. 64차원 그대로는 불안정해서 PCA 30차원 위에서 — 5-14 예고. 판정: 합격(0.836, 군집팀 1위).
- **5-14 PCA (차원축소팀, PC)**: 가장 퍼진 방향(분산)으로 축 돌리기, 성분 그림(8×8로 보이는 "고유 숫자"), 설명된 분산 곡선, 2성분으로 복원한 흐린 글씨(얼마를 버렸나). 2D 지도 60.3% → 합격선 18.1% 넘음(합격), 하지만 겹침이 많다(초파리의 지적) — 5-15 예고. 다른 지원자의 전처리로 쓰인다(GMM).
- **5-15 t-SNE · UMAP (차원축소팀, tS)**: 이웃 관계를 지키며 펼치기. perplexity·n_neighbors 효과, 무리 사이 거리와 무리 크기는 믿지 말 것, 새 데이터 배치(UMAP은 transform 가능, t-SNE는 불가), 시간. 97.6% 합격. 시리즈 마지막 편이므로 outro에 15명 전체 결산(5-0 매뉴얼 씨 포함, 본부별 합격·보류 표)과 단체 장면(sc_party), 5-0 전체 지도로 돌아가는 안내를 둔다. 결산 숫자는 out/의 각 편 결과(README 표)를 쓴다.
